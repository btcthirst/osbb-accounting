Планування екрану "Рух коштів" (Cash Flow)
Опис завдання
На основі аналізу XLSX файлу відомість по 311-23.xlsx необхідно реалізувати екран для відображення руху коштів по рахунку 311 (Поточний рахунок).

Структура даних з XLSX
Файл містить 13 аркушів (по одному на кожен місяць), кожен з якого має:

Заголовок: ОСББ інформація, назва звіту, період
Колонки:
Дата операції
Постачальник / Платник (контрагент)
Сума операції (Дт рах.311 - надходження)
Розподіл по кредитах рахунків (313, 63, 641, 641.1, 651, 94)
Загальна сума обороту по Кт
Бізнес-логіка
Рух коштів представляє собою об'єднану таблицю, яка показує:

Надходження (Дебет): платежі від власників
Витрати (Кредит): оплати постачальникам, комунальні послуги, тощо
Це по суті звіт, який агрегує дані з існуючих сутностей:

Payment
 (надходження)
Expense
 (витрати)
Підтверджені вимоги
IMPORTANT

Архітектурне рішення: Екран "Рух коштів" буде read-only звітом, який агрегує дані з існуючих таблиць payments та expenses. Не створюватиметься окрема доменна сутність CashFlow.

Підтверджено користувачем:

✅ Початковий баланс розраховується від нуля
✅ Деталізація по бухгалтерським рахункам реалізується через категорії витрат (використовуємо існуюче поле ExpenseCategory)
✅ Необхідна функція експорту в XLSX
✅ Фільтрації по місяцю/року достатньо (без довільних діапазонів)

Структури:

type ListCashFlowInput struct {
    CurrentUserID int64
    StartDate     *time.Time
    EndDate       *time.Time
    Month         *int
    Year          *int
    Limit         int
    Offset        int
}
type CashFlowEntry struct {
    ID            int64
    Date          time.Time
    Type          string // "payment" або "expense"
    Counterparty  string // Платник або Постачальник
    Description   string
    Debit         float64 // Надходження
    Credit        float64 // Витрати
    Balance       float64 // Поточний баланс (розраховується)
}
type ListCashFlowOutput struct {
    Entries      []*CashFlowEntry
    Total        int64
    TotalDebit   float64
    TotalCredit  float64
    StartBalance float64
    EndBalance   float64
}
