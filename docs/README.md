## Огляд Проєкту

OSBB Accounting — це десктопний додаток для управління фінансами ОСББ (Об'єднання Співвласників Багатоквартирного Будинку). Він дозволяє вести облік квартир, власників, нарахувань, платежів та витрат, а також генерувати звіти.

**Технології:**
- **Backend/Core:** Go (Golang)
- **UI:** Fyne Framework
- **Database:** SQLite
- **Architecture:** Clean Architecture

---

## Архітектура

Проєкт побудований за принципами **Clean Architecture** (Чиста Архітектура), що забезпечує незалежність бізнес-логіки від зовнішніх фреймворків та баз даних.

### Шари (Layers)

1.  **Domain Layer (`domain/`)**:
    -   Це серце додатку. Містить бізнес-сутності (`entity`) та інтерфейси репозиторіїв (`repository`).
    -   Цей шар не залежить від жодного іншого шару.

2.  **Application Layer (`application/`)**:
    -   Містить бізнес-сценарії (`usecase`) та сервіси (`service`).
    -   Визначає, *що* робить додаток. Оркеструє потік даних між UI та Domain шарами.

3.  **Infrastructure Layer (`infrastructure/`)**:
    -   Реалізує інтерфейси, визначені в Domain шарі.
    -   Тут знаходиться робота з базою даних (`persistence/sqlite`), файловою системою, зовнішніми API.

4.  **Presentation Layer (`presentation/`)**:
    -   Відповідає за взаємодію з користувачем.
    -   Реалізовано за допомогою Fyne (`fyne/`).
    -   Містить екрани (`screens`), діалоги (`dialogs`) та компоненти UI.

## Ключові Концепції

### Repository Pattern
Весь доступ до даних здійснюється через інтерфейси репозиторіїв. Це дозволяє легко замінити SQLite на іншу базу даних (наприклад, PostgreSQL) без змін у бізнес-логіці.

### Dependency Injection (DI)
Залежності передаються через конструктори. Ми використовуємо `ServiceContainer` для ініціалізації та зберігання всіх сервісів при запуску додатку.

### UI Components
Для забезпечення консистентності інтерфейсу ми використовуємо набір helper-функцій для створення кнопок, таблиць та полів вводу.
Детальніше: [COMPONENTS_GUIDE.md](COMPONENTS_GUIDE.md)

## Модулі Системи

### 1. Квартири (`Apartments`)
Управління списком квартир.
- Поля: Номер, Площа, Поверх, Кількість кімнат.
- Функції: Створення, Редагування, Пошук.

### 2. Власники (`Owners`)
Управління даними власників.
- Поля: ПІБ, Телефон, Email, Telegram.
- Зв'язок: Власник може мати частку власності в квартирі (`Ownership`).

### 3. Нарахування (`Charges`)
Щомісячні нарахування для квартир (квартплата).
- Автоматичний розрахунок на основі тарифу та площі.

### 4. Платежі (`Payments`)
Облік надходжень від власників.
- Впливає на баланс квартири.

### 5. Витрати (`Expenses`)
Облік витрат ОСББ.
- Категоризація витрат (наприклад, "Електроенергія", "Зарплата", "Ремонт").

### 6. Рух Коштів (`CashFlow`)
Зведена таблиця всіх фінансових операцій (Платежі + Витрати) для аналізу балансу.

## База Даних

Ми використовуємо **SQLite**. Файл бази даних за замовчуванням створюється в домашній директорії користувача: `~/.osbb-accounting/osbb.db`.

### Міграції
Зміни в схемі БД керуються через міграції в папці `migrations/`. При запуску додаток автоматично застосовує нові міграції.

## Гайд для Розробників

### Як додати нову фічу

1.  **Domain**: Створіть сутність в `domain/entity` та інтерфейс репозиторію в `domain/repository`.
2.  **Infrastructure**: Реалізуйте репозиторій в `infrastructure/persistence/sqlite`.
3.  **Application**: Створіть Use Case та Service в `application/`.
4.  **Presentation**: Створіть екран в `presentation/fyne/screens` та додайте його в меню.
5.  **Bootstrap**: Зареєструйте нові сервіси в `cmd/bootstrap`.

### Корисні команди

- Запуск: `go run cmd/main.go`
- Тести: `go test ./...`
- Створення міграції: Створіть новий `.sql` файл в `migrations/`.
