# ОСББ Облік - Система Обліку Платежів та Боргів

Кросплатформний десктопний додаток для управління фінансами ОСББ, розроблений на Go з використанням Fyne UI framework.

## 🎯 Особливості MVP

- ✅ **Аутентифікація користувачів** з BCrypt хешуванням паролів
- ✅ **RBAC (Role-Based Access Control)** - три ролі: Адміністратор, Голова ОСББ, Бухгалтер
- ✅ **Clean Architecture** з Repository Pattern (готовність до міграції на PostgreSQL)
- ✅ **Кросплатформність** - працює на Windows, macOS, Linux
- 🔄 Управління квартирами (в розробці)
- 🔄 Облік платежів (в розробці)
- 🔄 Звітність про борги (в розробці)
- 🔄 Експорт у Excel (в розробці)

## 🛠 Технологічний Стек

- **Мова:** Go 1.21+
- **UI Framework:** Fyne v2.4.3
- **База Даних:** SQLite 3 (з можливістю міграції на PostgreSQL)
- **Безпека:** BCrypt для хешування паролів
- **Архітектура:** Clean Architecture + Repository Pattern

## 🚀 Встановлення та Запуск

### 1. Клонування репозиторію

```bash
git clone <repository-url>
cd osbb-accounting
```

### 2. Встановлення залежностей

```bash
go mod download
```

### 3. Запуск додатку

```bash
go run main.go
```

При першому запуску автоматично:
- Створюється директорія `~/.osbb-accounting/`
- Ініціалізується база даних SQLite
- Виконуються міграції
- Створюється дефолтний адміністратор

### 4. Перший вхід

**Дефолтні облікові дані:**
- **Ім'я користувача:** `admin`
- **Пароль:** `admin123`

⚠️ **ВАЖЛИВО:** Змініть пароль після першого входу!

## 📊 Архітектура

Додаток побудований за принципами **Clean Architecture**:

```
┌─────────────────────────────────────────┐
│         UI Layer (Fyne)                 │
│  ┌─────────────┐  ┌──────────────┐     │
│  │ Login Screen│  │  Main Window │     │
│  └─────────────┘  └──────────────┘     │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│      Business Logic Layer               │
│  ┌──────────────┐  ┌──────────────┐    │
│  │ AuthService  │  │ UserService  │    │
│  └──────────────┘  └──────────────┘    │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│   Data Access Layer (Repository)        │
│  ┌─────────────────────────────────┐    │
│  │  UserRepository (Interface)     │    │
│  └──────────────┬──────────────────┘    │
│                 │                        │
│  ┌──────────────▼──────────────────┐    │
│  │ SQLiteUserRepository (Impl)     │    │
│  └──────────────┬──────────────────┘    │
└─────────────────┼────────────────────────┘
                  │
┌─────────────────▼────────────────────────┐
│           SQLite Database                │
│         (~/.osbb-accounting/osbb.db)     │
└──────────────────────────────────────────┘
```

### Ключові Принципи:

1. **Repository Pattern** - весь доступ до БД через інтерфейси
2. **Dependency Injection** - сервіси отримують залежності через конструктори
3. **Separation of Concerns** - чітке розділення відповідальностей
4. **Database Agnostic** - легка міграція з SQLite на PostgreSQL

## 👥 Ролі Користувачів

| Роль | Опис | Права доступу |
|------|------|---------------|
| **Адміністратор** | Повний контроль | Всі модулі + управління користувачами |
| **Голова ОСББ** | Перегляд та затвердження | Перегляд звітів, управління квартирами |
| **Бухгалтер** | Фінансові операції | Введення платежів, генерація рахунків |

## 🔒 Безпека

- **BCrypt** хешування паролів (cost=12)
- **RBAC** - перевірка прав на рівні domain моделі
- **М'яке видалення** користувачів (збереження історії)
- **SQL інʼєкції** - захист через підготовлені запити
